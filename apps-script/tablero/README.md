# Tablero Apps Script

Código local final del tablero de finanzas, preparado como copia pública sin información personal.

Instalación, funciones y límites: [guía del tablero](../../docs/tablero.md).

Primero prepara una hoja propia con la [plantilla de datos](../../docs/modelo-datos.md). Después crea en su proyecto de Apps Script los archivos `Codigo.gs`, `Index.html` y `appsscript.json`. El usuario de Telegram de ejemplo debe configurarse antes de usar el botón Bot.

Esta entrega no confirma una implementación en Google ni incluye credenciales.
